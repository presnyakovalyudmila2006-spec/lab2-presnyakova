В данной лабораторной работе изучаются системы контроля версий.
Основное внимание уделяется работе с Git и платформой GitHub.
Планируется освоить базовые операции: клонирование, коммит, пуш.
Будет рассмотрена работа с ветками и создание Pull Request.
Также предстоит познакомиться с Issues и Projects на GitHub.
Освоены основные команды Git: git clone, git add, git commit, git push.

Создана ветка feature/update и выполнено слияние изменений через Pull Request.

Изучены возможности GitHub Issues и Projects для управления задачами.
